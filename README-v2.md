# Built locally - interactive Annual Report 2026 infographic

This GitHub Pages-ready prototype contains:
- `index-v2.html`
- `styles-v2.css`
- `data-v2.js`
- `app-v2.js`

## Preview locally
Open `index-v2.html` in a browser. No server or external dependency is required.

## Publish
Upload the four files to the root of a GitHub repository. Rename `index-v2.html` to `index.html`, then enable GitHub Pages from the repository's `main` branch and root folder.

## Accessibility included
- Semantic landmarks and logical heading hierarchy
- Keyboard-operable reading modes, tabs, forms and accordions
- Arrow-key navigation for theme tabs
- Skip link and strong focus indication
- Responsive reflow and scalable type
- Reduced-motion media query and manual control
- High-contrast mode
- Live story-result count
- No autoplay, flashing content, drag-only interaction or colour-only instructions

## Content and rights
Content is condensed from the European Committee of the Regions' EU Annual Report on the State of Regions and Cities 2026. The report states CC BY 4.0 reuse unless otherwise noted.
